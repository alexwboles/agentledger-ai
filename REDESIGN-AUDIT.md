# REDESIGN-AUDIT — agentledger-ai (2026-10-13)

Competitors researched (GRC / AI-agent governance):
1. **Drata** — dark navy sidebar (220px, #0f172a) with sectioned nav (Overview → Dashboard; Third-Party Risk → Vendors / Assessments / Risk Register / Continuous Monitoring; Compliance → Controls / Policies; Reports); risk register with likelihood×impact scoring and identify→score→treat→retest cycle; underline tab nav with count badges. Also launched an AI Agent Governance module (2026) with sensor-based discovery, policy simulation on real traffic, and per-agent trust scoring.
2. **Vanta** — Agentic Trust Platform; Risk Graph (real-time map of how risks connect and spread, high-impact issues pinned, guided remediation); continuous-monitoring ticker that turns red the moment a control fails; 24/7 AI GRC-engineer guidance; light theme with dark-ink chrome.
3. **SecureFrame** — same category language: control-centric lists, status pills, evidence packs, audit-ready export.
4. **W&B-style ML consoles** (secondary reference for data-dense tables): dense comparison tables, color-coded runs, count badges.

## Visual gaps (current vs. competitors)
1. **No navigation.** The app is a single long scroll under a masthead. Drata/Vanta have a persistent sectioned sidebar nav — the single biggest "real software" signal missing.
2. **Themed, not commercial.** The dark "bound ledger / folio Nº 001" parchment theme is distinctive but reads as a theme experiment, not a GRC tool. Drata/Vanta/SecureFrame are light-content with dark-ink chrome. The quirky "Solo-operator edition" kicker actively undercuts enterprise trust.
3. **Rounded corners everywhere** (btn 8px, panel 12px, agent rows 10px, chips 999px pills, toast 999px, xbtn 50% circles) — violates Alex's no-rounded-edges rule and reads "vibe coded" next to real tools.
4. **Broken CSS variables.** The late "feature batch" block references `var(--line)`, `var(--card)`, `var(--muted)` which are never defined in `:root` — so the Reviews strip and filter inputs render without borders/backgrounds (declarations are invalid and dropped). Real visual bug.
5. **KPI cards are "FIG. 1" folio-styled** with serif numerals; real tools use plain stat cards, tabular numerals, and small status annotations.
6. **Findings panel** has no severity filter/tabs; Drata uses underline tabs with count badges.
7. **Map legend** uses 50%-radius dots and dashed-line demo; needs sharp markers and a proper key.
8. **Modal/drawer chrome** is dark-on-dark with weak focus states; real tools use light surfaces, hairline borders, 2px focus outlines.
9. **Mobile:** masthead stacks awkwardly; no collapsible nav; KPI grid goes 2-col but cards keep folio styling.

## Functional / flow gaps
1. No section navigation or wayfinding (breadcrumbs, active section) — 4 long sections.
2. No live count badges (findings, high-risk, shadow) anywhere in chrome — Drata puts them on nav items.
3. Findings list can't be filtered by severity.
4. Remediation plan lives inside the map panel's blast area — discoverable only by clicking a map node; Drata gives remediation its own surface.
5. Review strip is present but visually broken (see #4 above) and buried under KPIs.
6. Export audit pack is the only "audit" surface; no visible audit-readiness summary (Vanta shows controls-green state).

## In scope for this redesign (highest impact first)
1. Persistent dark sidebar nav with section links + live count badges (findings / high-risk / shadow) — Drata's signature pattern.
2. Full light-theme restyle: white cards, hairline borders, zero border-radius, tabular numerals, brass "assurance seal" accent (distinctive, not a Drata clone), status colors reserved for risk language (green/amber/red).
3. Fix the undefined-CSS-var bug (reviews strip, filter bar) as part of the rewrite.
4. Slim top utility bar: breadcrumb + the 5 existing action buttons, same IDs/behavior.
5. Findings panel: underline severity tabs with counts (All / Block / Warn / Info) — rendered from existing `R.buildFindings` data, no engine change.
6. Risk map panel: keep the SVG engine, restyle chrome; dark "situation room" panel inside the light UI (Vanta Risk-Graph nod), scoped CSS-var overrides so zero JS changes.
7. Drawer + modal: light surfaces, sharp corners, focus states; remediation planner tab already exists in drawer tabs.
8. Mobile: sidebar collapses to a top bar with horizontally scrolling nav; no horizontal scroll anywhere.

## Out of scope
- New risk-engine features, new data fields, backend, multi-user, real integrations (product is intentionally local-first).
- A separate remediation page (planner stays in the blast panel + drawer; one redesign, not a re-architecture).

## Regression contract
- All 44 DOM IDs consumed by `js/app.js` preserved.
- All ~100 CSS classes generated by `js/app.js` restyled (no orphan selectors).
- `test/smoke.sh` + `test/e2e.sh` stay green; extend smoke with a no-rounded-corners check and a defined-vars check.
